# LightCycles (HTML5 Canvas Edition)

A browser-based two-player **Tron LightCycles** clone built with **vanilla JavaScript** and the **Canvas API**. No frameworks. No dependencies. Pure fun.

## 🎮 Gameplay

* Two players control light cycles leaving deadly trails.
* The first to crash (into a wall or trail) loses.
* Fast-paced, grid-based action rendered on an HTML5 canvas.

### Controls

| Player | Keys          |
| ------ | ------------- |
| 1      | W / A / S / D |
| 2      | Arrow Keys    |

## 🛠️ Setup

No build tools needed. Just open the `index.html` file in any modern browser.

### Run locally

```bash
git clone https://github.com/yourname/lightcycles-canvas.git
cd lightcycles-canvas
open index.html
```

Or simply double-click `index.html` in your file manager.
